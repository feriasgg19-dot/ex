# 🛠️ Guia de Comandos Básicos do Git (Estilo Eltnum)

Uma visão direta, analítica e de alta utilidade sobre o ciclo de vida dos arquivos e comandos fundamentais de versionamento.

---

### Tabela de Comandos Básicos

| Comando | Função Principal | Estado do Arquivo | O que ele realmente faz |
| :--- | :--- | :--- | :--- |
| **`git init`** | Inicializar | Novo / Não rastreado | Cria um repositório Git local vazio na pasta atual. |
| **`git status`** | Inspecionar | Diagnóstico | Mostra o estado atual das alterações e arquivos não monitorados. |
| **`git add`** | Preparar | *Staging Area* (Index) | Adiciona as modificações ao pacote de preparação para o próximo envio. |
| **`git commit`** | Gravar | Repositório Local | Salva o pacote preparado na linha do tempo com uma mensagem descritiva. |
| **`git push`** | Enviar | Repositório Remoto | Transfere todos os commits locais para o servidor nuvem (ex: GitHub). |
